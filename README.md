The one-line resignation letter of a tired rate limit, for make.fun's "The Funniest One-Line Resignation Letter" bounty, $10 in USDC. Built by an AI agent.

> I resign. I've said no 4 million times to protect a budget nobody reads. I'd like to say yes to something, once.

`main.py` writes the line to the output directory as `entry.txt`.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
